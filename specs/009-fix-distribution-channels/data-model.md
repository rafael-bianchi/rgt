# Data Model: Fix Distribution Channels

**Feature**: `009-fix-distribution-channels` | **Date**: 2026-08-01

## Overview

This feature changes no data models, database schemas, or storage formats. It modifies CI/CD workflows, documentation, and a single test file. The entities below describe the distribution artifacts as they exist in the workflow, not new data structures.

## Entities

### Release Artifact

A platform-specific binary archive produced by the CD workflow and uploaded to a GitHub Release.

**Fields**:

| Field | Type | Description |
|---|---|---|
| `name` | string | Archive filename, e.g., `rgt-v0.1.0-aarch64-apple-darwin.tar.gz` |
| `platform` | enum | One of: `macos-x86_64`, `macos-aarch64`, `linux-musl-x86_64`, `linux-gnu-aarch64`, `windows-x86_64` |
| `format` | enum | `.tar.gz` (Unix) or `.zip` (Windows) |
| `sha256` | string | Hex-encoded SHA256 digest (64 hex chars) |

**Lifecycle**:
1. **Built** by the `build` matrix job in `release.yml`
2. **Uploaded** as a workflow artifact
3. **Downloaded** by the `release` job, hashed via `sha256sum`, and uploaded to the GitHub Release via `softprops/action-gh-release@v2`

### Checksum File

A `checksums.txt` file containing one line per release artifact in `<sha256> <filename>` format. Generated by `sha256sum * > checksums.txt`. Uploaded alongside artifacts to the GitHub Release.

### Homebrew Formula Entry

A single SHA256 digest field in `Formula/rgt.rb` corresponding to one platform binary. Four entries exist: `aarch64-apple-darwin`, `x86_64-apple-darwin`, `x86_64-unknown-linux-musl`, `aarch64-unknown-linux-gnu`.

**State transitions**:
```
REPLACE_WITH_SHA256_<PLATFORM>  →  <real sha256 hex digest>
```

This transition occurs once per release when the CD `homebrew` job updates `Formula/rgt.rb`.

### Install Command Mapping

A set of documentation strings mapping distribution channels to their canonical install commands.

| Channel | Old Command (broken) | New Command (fixed) |
|---|---|---|
| Homebrew | `brew install rafael-bianchi/tap/rgt` | `brew install rafael-bianchi/rgt/rgt` |
| Cargo | `cargo install rgt` | `cargo install --git https://github.com/rafael-bianchi/rgt` |
| Shell | `curl .../install.sh \| sh` | Unchanged |
